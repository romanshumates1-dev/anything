## Combining Videos

After generating all 3 videos:

1. Download each MP4 from HeyGen
2. Use free tools to combine:
   - **Canva** (free): Upload → Create video → Add all clips → Export
   - **CapCut** (free): Import → Arrange → Add transitions → Export
   - **DaVinci Resolve** (free, pro-level): Timeline → Add clips → Export

### Suggested Transitions
- 0.5 second crossfade between videos
- Add DealFlow AI logo at start (3 sec) and end (5 sec)
- Background music: Subtle corporate/tech (Epidemic Sound or Artlist)

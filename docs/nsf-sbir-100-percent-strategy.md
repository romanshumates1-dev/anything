## MULTI-PROGRAM HEDGE STRATEGY

### The Math of Hedging

If you apply to 3 independent programs, each with 50% success:
- P(at least one success) = 1 - (0.5)³ = **87.5%**

If you apply to 5 programs with 50% success:
- P(at least one success) = 1 - (0.5)⁵ = **96.9%**

If 4 programs at 60% each + 1 near-certain:
- P(success) = 1 - (0.4)⁴ × 0.05 = **99.9%**
